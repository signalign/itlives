# It Lives!

*Zombie Modernism and White Supremacy in Canadian Graphic Design Culture* by Stephan Rosger.

A standalone, responsive rebuild of the essay site. Everything is static: `index.html` plus the images in `assets/`. Videos stream from YouTube.

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000. YouTube embeds play inline when the page is served over http(s).

## Hosting

Served with GitHub Pages from the `main` branch root.
